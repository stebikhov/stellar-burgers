# Cypress E2E тесты для конструктора бургеров

## Описание

Интеграционные тесты на Cypress для страницы конструктора бургеров.

## Структура

- `e2e/constructor.cy.tsx` - основные тесты конструктора
- `fixtures/ingredients.json` - моковые данные ингредиентов
- `fixtures/user.json` - моковые данные пользователя
- `fixtures/order.json` - моковые данные заказа

## Запуск тестов

### Открыть Cypress в интерактивном режиме

```bash
npm run cypress:open
```

### Запустить тесты в headless режиме

```bash
npm run cypress:run
```

## Data-cy атрибуты

Для тестирования используются следующие data-cy атрибуты:

- `[data-cy="{ingredient_id}"]` - карточка ингредиента
- `[data-cy="ingredient-count"]` - счетчик ингредиента
- `[data-cy="constructor-bun-top"]` - верхняя булка
- `[data-cy="constructor-bun-bottom"]` - нижняя булка
- `[data-cy="constructor-ingredients"]` - список начинок
- `[data-cy="order-total"]` - общая стоимость
- `[data-cy="order-button"]` - кнопка оформления заказа
- `[data-cy="modal"]` - модальное окно
- `[data-cy="modal-close"]` - кнопка закрытия модального окна
- `[data-cy="modal-overlay"]` - оверлей модального окна
- `[data-cy="order-modal"]` - модальное окно заказа
- `[data-cy="order-number"]` - номер заказа

## Моковые данные

### Ингредиенты

Файл `fixtures/ingredients.json` содержит тестовые ингредиенты:

- Булки (bun)
- Основные ингредиенты (main)
- Соусы (sauce)

### Пользователь

Файл `fixtures/user.json` содержит данные тестового пользователя.

### Заказ

Файл `fixtures/order.json` содержит ответ сервера при создании заказа.

## Перехват запросов

Тесты используют `cy.intercept()` для перехвата следующих запросов:

- `GET api/ingredients` - получение списка ингредиентов
- `GET api/auth/user` - получение данных пользователя
- `POST api/orders` - создание заказа

## Требования

- Node.js >= 16
- Cypress >= 13
- Приложение должно быть запущено на `http://localhost:4000`
